# Support

## Where to get help

- **Usage questions and workflows:** GitHub Discussions on this repository.
- **Bug reports and reproducible defects:** GitHub Issues using the bug report form.
- **Security problems:** see [`SECURITY.md`](SECURITY.md), never a public issue.
- **Chutes service questions** (accounts, quotas, billing, model availability): use the official
  Chutes documentation at <https://chutes.ai/docs> or Chutes support channels.

## Before asking

1. Check the README troubleshooting section.
2. Search existing issues and discussions.
3. Reproduce on the latest release with a clean configuration.

## What support covers

This is a free, maintainer-run project. Support covers defects in this project's latest release and
questions about documented behavior. It does not cover customized deployments, third-party
integrations or consulting work.

## Upstream

Chutes Build is an independent fork of [`xai-org/grok-build`](https://github.com/xai-org/grok-build).
A problem that reproduces on the upstream project and does not involve Chutes endpoints belongs in
that project's tracker, not here.

## Response expectations

Best effort, usually within a week. Issues without version information or a reproduction may be
closed with a request for details.
